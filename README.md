# 🛒 Ecommerce Backend (Spring Boot)

## 📌 Overview

It is part of my learning journey to build a full-stack ecommerce system.

* Java
* Spring Boot
* Spring Data JPA
* PostgreSQL
* Maven

* PostgreSQL database integration
* User entity creation
